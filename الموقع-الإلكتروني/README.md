# موقع رائحة أمي

الموقع نفسه موجود في مجلد `docs/` بالمشروع، ويشتغل على GitHub Pages:
https://moh71222-pixel.github.io/Mom-smell/

- `docs/index.html`: الصفحة (المقطع، المجموعة، حكايتنا، كيف تطلب).
- `docs/style.css`: الألوان والخطوط والتصميم.
- `docs/app.js`: تشغيل المقطع مع التمرير.
- `docs/assets/`: الشعارات، الملصقات، صور المنتجات، الخطوط، والمقطع.

في هذا المجلد:
- `مقطع-تكوير-المعمول.mp4`: المقطع الكامل (15 ثانية): المواد الخام تتجمع وتتكور وتصير كرة معمول.
- `صور-المنتجات/`: صور العائلات الأربع وصورة بداية ونهاية المقطع.

لتعديل سعر: افتح `docs/index.html` وابحث عن اسم المنتج، السعر مكتوب بجانبه (مثال: `130 ر.س`).
