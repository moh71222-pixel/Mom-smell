# موقع رائحة أمي

- الرابط: https://raihatummi.higgsfield.app (مبني على Higgsfield)
- `مقطع-تكوير-المعمول.mp4`: المقطع الكامل (15 ثانية): المواد الخام تتجمع وتتكور وتصير كرة معمول. بالموقع يشتغل مع التمرير (سكرول) ومقسوم على 4 فصول: الخامات، الخلطة، التكوير، المعمول.
- `صور-المنتجات/`: صور العائلات الأربع وصورة بداية ونهاية المقطع.
- `كود-الموقع/`: ملفات الصفحة، قائمة المنتجات والأسعار (`src/catalog.ts`)، الألوان والخطوط (`src/styles.css`).

لتعديل سعر أو منتج: عدّل `src/catalog.ts`.
