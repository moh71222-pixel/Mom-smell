# خط رائحة أمي — Raihat Kufi

الخط الخاص بالبراند. كوفي هندسي عريض، والتعديلات اللي تخليه خاص:

1. **نقاط على شكل معين نجدي** بدل النقاط الدائرية، في كل الحروف (ب ت ث ي ة ش …).
2. **ألف الباب (ss02):** الألف يصير باب قلعة حائلية بشُرَف مثلثة. يتفعّل من إعدادات «Stylistic Set 2» في البرنامج.
3. **زخارف خاصة** تُكتب بالخط نفسه:
   - U+E000 باب القلعة
   - U+E001 جبلا أجا وسلمى
   - U+E002 صف المثلثات النجدية
   - U+E003 المعين
   - U+E004 خط الدخان

## الملفات
- `RaihatKufi-Regular.ttf`: للتثبيت على الجهاز (فوتوشوب، إليستريتر، كانفا، وورد).
- `RaihatKufi-Regular.woff2`: للموقع.
