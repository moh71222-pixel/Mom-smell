# شعار رائحة أمي — RAIHAT UMMI (ملفات نهائية)

مرسوم بالكامل كملفات فكتور (SVG) بخطوط حقيقية، بدون ذكاء اصطناعي. الـSVG يُطبع بأي مقاس بدون ما يتشوه.

| الملف | الاستخدام |
|---|---|
| شعار-رئيسي | العلب والملصقات والموقع |
| شعار-رئيسي-معكوس | على الخلفيات الغامقة |
| شعار-رئيسي-خلفية-رملية | المطبوعات والكروت |
| شعار-رئيسي-لون-واحد | الختم والحفر والطباعة بلون واحد |
| شعار-أفقي / معكوس | ترويسة الموقع والفواتير والغلاف |
| أيقونة-الحساب | صورة إنستقرام وتيك توك |
| الرمز | الرمز لحاله بخلفية شفافة |
